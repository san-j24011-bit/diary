# ユーザー名・パスワード認証の設定

## シートを手動で準備
スプレッドシート「日記アプリ」に以下のシートを作成します。プログラムはシートを自動作成しません。

- users: 1行目に id / username / password_hash / salt / iterations / name / created_at（created_atは任意）
- sessions: 1行目に user_id / token_hash / expired_at
- diary: 既存の owner_id / date / title / content / mood / updated_at を維持します。

usersの列A〜Dは、入力前に表示形式を「書式なしテキスト」にしてください。古いemail/password列の平文パスワードは使用しません。旧sessionsのtoken列も使用しません。

## アプリ画面から新規登録
シートの列名を準備してGAS・フロントエンドを更新すると、ログイン画面の「新規登録」から登録できます。ユーザー名、任意の表示名、5〜128文字のパスワード、確認用パスワードを入力してください。ユーザー名は重複できません。成功後は自動ログインします。usersへ事前にユーザー行を追加する必要はありません。

## アカウント作成（管理者向けの代替方法）
VSCodeのターミナルで、プロジェクト直下から実行します。

    node gas/create-user.cjs

ユーザー名の文字種・3文字以上・40文字以下の制限はありません。日本語・絵文字・記号・内部の空白も使えます。前後の空白は除去し、英字の大文字小文字は区別しません。空欄と重複は登録できません。パスワードは5文字以上で、非表示入力を2回行います。表示されたタブ区切りの1行をusersの2行目以降に貼り付けます。ユーザー名とidは重複させないでください。
出力のpassword_hashは認証に使える秘密情報です。Git・チャット・公開ファイルに貼り付けないでください。

パスワード変更は、同じユーザー名で行を生成してpassword_hash・salt・iterationsだけを既存行へ置き換え、sessionsの該当user_idの行を削除します。idは変更しません。

## GASの更新
初回はユーザーがApps Scriptでウェブアプリとしてデプロイします。既存デプロイの更新はgas内で実行します。

    clasp push
    clasp version "Add username login"
    clasp deploy -i AKfycbyyjZigB9NvChT9dhJHPZ1xTsaqlR2QvKFYGqK1KASHZEIg85gTOGQ6pEWxUaK8uCL0

認証用のusers/sessionsを用意してからバックエンドとフロントエンドを更新してください。旧バックエンドに新ログイン画面だけを公開しても動きません。新バックエンドは旧版の匿名保存を拒否します。

## 動作
- 平文パスワードは送信しません。ブラウザーでPBKDF2-SHA256（210000回）を実行し、GASが発行する2分有効・一度限りのチャレンジにHMACで応答します。
- セッションは24時間有効。ブラウザーのsessionStorageに保持し、GASにはトークンのSHA256のみ保存します。ログアウトはサーバー側のセッションも無効化します。
- GET制約によりセッショントークンと日記はURLパラメーターに入ります。エンドポイントのログや共有URLは公開しないでください。
- アカウント別にローカル保存と再試行キューを分けます。ログインにはネット接続が必要です。ログイン中はオフラインでもローカル保存できます。
- 5回の認証失敗後、約15分は再試行を止めます。GASキャッシュによる制限であり、キャッシュ消去時には解除されます。
- セルフ登録に対応します。登録用の一時キーはHTTPS応答で渡し、認証用ハッシュをマスクしてGETで送信します。一時キーはURLに含めず、一度限り・2分で失効します。
- パスワード再設定メールは提供しません。忘れた場合は管理者に連絡してください。
- 以前のブラウザーごとの日記は旧localStorageに残します。既存owner_idは自動でアカウントに割り当てません。ログイン後の「このブラウザーの以前の日記を取り込む」で、確認したアカウントへ取り込めます。同じ日付は上書きせず、旧データも残します。
- ローカル保存は暗号化されていません。共有端末ではブラウザープロファイルを分けてください。

## 確認
ユーザーA・Bを用意し、Aで保存した記録がBに表示されないこと、未ログインの保存/取得/削除が拒否されること、ログアウトしたトークンが使えないことを確認します。

## 新規登録者の一覧
アプリから登録するとusersシートへ1人1行で追加します。usernameはユーザー名、nameは表示名、idはユーザーIDです。
登録日時を表示するには、usersの1行目の空いている列にcreated_atを追加してください。以後の新規登録の日時を記録します。既存ユーザーの日時は空欄のままです。
認証用のpassword_hash・salt・iterations列は非表示にすると一覧を見やすくできます。非表示はアクセス制御ではありません。usersシート自体を一般公開しないでください。
